About the Aspect Ratio & Grid

Type a size such as 1920x1080 and get its reduced ratio (16:9), the decimal value, scaled heights for common widths and the matching CSS aspect-ratio declaration. Below that, set the number of columns, the gap and the container width, and it tells you the exact pixel width each grid column ends up with.

Tip: Use the aspect-ratio line for video embeds and card images to avoid layout shift, because the browser can reserve the space before the media loads.

Aspect Ratio & Grid is free, needs no sign-up and runs entirely in your browser, so what you paste never leaves your device.

How to use it

  1. Paste or type your input, or press Ctrl+V anywhere on the page.
  2. Adjust the options. The result updates instantly.
  3. Copy the output with the Copy button or Ctrl+C.
