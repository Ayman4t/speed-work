About the CSV → Markdown / HTML

Copy a block of cells from a spreadsheet and turn it into a Markdown table for a README, wiki or issue, or into clean HTML table markup with thead and tbody for a web page. The first row becomes the header. The HTML output escapes special characters, so symbols like ampersands and angle brackets in your data do not break the page.

Tip: Markdown tables render as plain text in some editors, so keep the cell contents short. For long text, the HTML output gives you more room to add classes and styling afterwards.

CSV → Markdown / HTML is free, needs no sign-up and runs entirely in your browser, so what you paste never leaves your device.

How to use it

  1. Paste or type your input, or press Ctrl+V anywhere on the page.
  2. Adjust the options. The result updates instantly.
  3. Copy the output with the Copy button or Ctrl+C.
