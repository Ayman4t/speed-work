🔍 Diff Checker

Compare two texts; additions green, deletions red.

About the Diff Checker

Compare two blocks of text line by line and see what changed. Lines only in the first text are marked in red with a minus sign, lines only in the second are green with a plus, and unchanged lines are shown in grey for context. It is useful for config files, copy revisions, API responses and anything else you would otherwise compare by eye.

Tip: Paste text A, add a line containing five equals signs (=====), then paste text B below it. The comparison works by whole lines, so a changed word flags the entire line it sits on.

Diff Checker is free, needs no sign-up and runs entirely in your browser, so what you paste never leaves your device.

How to use it

  1. Paste or type your input, or press Ctrl+V anywhere on the page.
  2. Adjust the options. The result updates instantly.
  3. Copy the output with the Copy button or Ctrl+C.
