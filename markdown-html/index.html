About the Markdown ⇄ HTML

Write Markdown on the left and get clean HTML along with a live preview. It supports the everyday syntax: headings, bold and italic, inline code, links, lists and paragraphs. It is a quick way to turn a README section or a draft post into markup you can paste into a CMS, an email template or a static page.

Tip: Check the preview for the links. For safety, only http, https, mailto and relative links are kept as live links, so other schemes will not be turned into clickable anchors.

Markdown ⇄ HTML is free, needs no sign-up and runs entirely in your browser, so what you paste never leaves your device.

How to use it

  1. Paste or type your input, or press Ctrl+V anywhere on the page.
  2. Adjust the options. The result updates instantly.
  3. Copy the output with the Copy button or Ctrl+C.
